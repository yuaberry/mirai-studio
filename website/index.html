Mirai Studio Pro

The core studio is free forever. Pro adds a storytelling toolset for adult-rated narratives — with the position stated plainly.

Pro license

Mature Content Mode

Unlocks R-18 storytelling: mature genres (Hentai, Erotica, Adult Drama), mature-rated projects and explicit artistic direction in generation prompts.

  • Adults-only, enforced in code. Explicit generation requires every cast character to have an explicitly adult age — minors and unstated ages are hard-blocked. Not a policy page: a runtime rule.
  • Story-first, by design. A conscientization flow states it before activation: this is a storytelling studio with adult-rated tools — not an adult-content generator, and never one.
  • Offline license keys. Ed25519-signed, validated locally — no account, no server, no telemetry. The private key never touches the app.

SFW remains the default. The mode only affects projects you rate 18+, and you own the legality of what you produce.
